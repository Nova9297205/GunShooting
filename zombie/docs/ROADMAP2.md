# DEAD NIGHTS 2D — 開発ロードマップ 第2弾（自走用）

テーマ：**もっと長く楽しめるゲームにする**。
「毎回ちがう展開」と「遊ぶたびに積み上がる目標」を増やす。

進め方のルールは第1弾（`ROADMAP.md`）と同じ。要点：

- 1 項目ずつ、次の順に進める：
  1. 実装する
  2. 合格条件のテストを通す
  3. 回帰テストを通す
  4. ビルドを通す
  5. コミット・push（作業ブランチのみ）
  6. この表と `EVAL_LOG.md` を更新する
- **main へのマージはしない**（頼まれたときだけ PR を作ってマージする）
- **ソロで進行不能にしない**。協力の要素には、必ず 1 人用の代わりの手段を置く
- **古いセーブを読めること**、3 人 P2P の同期、ページエラー 0 を毎回守る
- テストプレイの感想（`ROADMAP.md` 末尾の欄、またはこの会話）が届いたら最優先で反映する
- 3 回改善しても届かなければ、理由を書いて保留（⏸）にし、次へ進む
- 規模が大きく、ゲームの性格が変わる判断が要るときは、止まって質問する

状態：⬜ 未着手 / 🔧 作業中 / ✅ 合格 / ⏸ 保留

## 完成の条件（第2弾全体）

1. **毎回ちがう**：始め方・職業・ルールの変化の組み合わせが 50 通り以上ある。同じ組み合わせで遊んでも、世界の変化・勢力・出来事が毎回ちがう
2. **積み上がる**：救助・実績・図鑑で、次の回に選べる物が増える（解放要素 20 個以上）
3. **救助の後も続く**：エンディングが 2 つ以上（救助・治療薬）あり、救助の後に第 2 章（次の地域）へ進める
4. **破綻しない**：期限なしモードで 60 日のシミュレーションを回しても、詰み・増え続ける物・処理時間の悪化がない
5. 全項目が合格（または理由つきの保留）で、回帰テストがすべて通る
