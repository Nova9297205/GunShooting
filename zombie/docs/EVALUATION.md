# DEAD NIGHTS 2D — 評価項目（テーマ：お金を稼げるゲームに仕上げる）

想定する売り方：Steam などで **買い切り ¥1,200〜1,800 の 2〜3人協力サバイバル**。
「買ってもらえる（ストアで目を引く）」「返金されない（最初の2時間で面白さが伝わる）」
「遊び続けてもらえる（レビュー・口コミが増える）」「友達を誘いたくなる（協力プレイで売れる）」の4点を満たすことを目標にする。
課金で強くなる要素は入れない（レビューが荒れて売上が落ちるため）。

各機能を実装したら、下の **共通項目（C）** と **機能別項目（F）** をすべて確認する。
1つでも「不合格」があれば改善して、もう一度すべてを確認する（合格するまで繰り返す）。

確認の方法：
- 【自動】Playwright のテストで数値を測る（ソロ＋3人 P2P）
- 【画面】スクリーンショットを撮って目で確認する（1280×760 と スマホ横 844×390）

---

## 共通項目（すべての機能に適用）

| # | 観点（売上との関係） | 合格の条件 | 方法 |
|---|---|---|---|
| C1 | 安定性（返金・低評価を防ぐ） | `npm run build` 成功。ソロ・3人のテストでページエラー 0 件 | 自動 |
| C2 | 協力プレイの同期（協力ゲームとして売る前提） | ホストとゲスト2人で、その機能の状態（位置・数値・見た目）が一致する | 自動 |
| C3 | 続きから遊べる（長時間プレイを支える） | セーブ→ロードで、その機能の状態がそのまま戻る | 自動 |
| C4 | 性能（低スペック PC・ノート PC でも遊べる） | 3人時、ホストの計算が 1 フレーム平均 4ms 未満。ゲスト1人あたりの通信が 1 回 14KB 未満 | 自動 |
| C5 | 分かりやすさ（最初の2時間で離脱させない） | 初めて触ったとき、画面のヒント・説明だけで使い方が分かる。文字の重なり・はみ出しがない（PC・スマホ） | 画面 |
| C6 | 手応え（触って気持ちいい） | その機能の操作すべてに「見た目・音・メッセージ」のどれか2つ以上の反応がある | 自動＋画面 |
| C7 | ストア映え（ストアページで目を引く） | その機能が一目で分かる、ストアに載せられる見栄えのスクリーンショットが撮れる | 画面 |
| C8 | 協力の価値（友達を誘う理由になる） | 3人で遊ぶと有利になる・役割が分かれる、などの理由が1つ以上ある | 設計＋自動 |
| C9 | 続けたくなる（レビュー・口コミが増える） | 数分で達成できる目標と、数日（ゲーム内）かけて目指す目標の両方がある | 設計 |
| C10 | 既存機能を壊さない | これまでの回帰テスト（セーブ・再接続・大群の夜・タッチ操作・地区・3人同期・睡眠）がすべて通る | 自動 |

## 機能別項目

### F1 拠点づくり（夜にやることを作る）
| # | 合格の条件 |
|---|---|
| F1-1 | 建てられる物が 5 種類以上（防御・罠・明かり・生産・調理）あり、置く前に置ける場所かどうかが見える |
| F1-2 | 大群の夜、ゾンビがバリケードを壊しにくる。バリケード 6 枚で拠点に入るゾンビが半分以下になる |
| F1-3 | 「昼に集める → 夜に作る → 翌日が楽になる」がつながる：雨水＋菜園の収穫＋缶詰で温かい料理ができ、普通の食事より効果が高い |
| F1-4 | 壊れた物は修理できる。作った物は拠点の外には置けない（拠点を作り込む楽しさに集中させる） |

### F2 遠征の動機づけ（昼にやることを作る）
| # | 合格の条件 |
|---|---|
| F2-1 | 無線で毎朝 2〜3 件の依頼が届き、目的地が地図・コンパスに出る |
| F2-2 | 依頼は地区の特徴と合っている（病院なら薬、軍事施設なら弾薬など）。遠い・危険なほど報酬が多い |
| F2-3 | 地図に「調べた建物」と「まだ調べていない建物」が分かれて表示される。調べた割合が見える |
| F2-4 | 1 件の依頼を片道 1〜4 分（ゲーム内の昼の 1/10〜1/3）で達成できる |

### F3 車両
| # | 合格の条件 |
|---|---|
| F3-1 | 燃料・修理部品を見つけて車を直すと運転できる。燃料が減る |
| F3-2 | 運転手 1 人＋同乗者 2 人まで乗れる。同乗者は窓から撃てる（協力の価値） |
| F3-3 | ゾンビを轢ける。轢くと車が傷む。壁や車にぶつかると止まる。川は橋でしか渡れない |
| F3-4 | トランクが倉庫として使える |
| F3-5 | ゲストの画面で車の動きがカクつかない（位置のずれが 1 タイル未満） |
| F3-6 | 歩くより 2.5 倍以上速く遠征でき、エンジン音でゾンビが集まる（便利さと危険の釣り合い） |

### F4 体調（疲労・寒さ・ケガ）
| # | 合格の条件 |
|---|---|
| F4-1 | 疲労：眠らずに丸 1 日以上起きていると、狙いがぶれて足が遅くなる。眠ると治る |
| F4-2 | 寒さ：雨・嵐・夜の屋外で体が冷える。焚き火・屋内・服で温まる。冷えるとスタミナの回復が落ちる |
| F4-3 | ケガ：出血（包帯で止まる）・骨折（添え木で治る、治るまで足が遅い）の 2 種類以上 |
| F4-4 | 体調の悪い所が画面で一目で分かり、何を使えば治るかが表示される |
| F4-5 | 管理が面倒すぎない：普通に遊んでいて、体調の対応に使う時間は 1 日の 1 割未満 |
