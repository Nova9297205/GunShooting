DEAD NIGHTS 2D

2〜3人協力 ポストアポカリプス探索サバイバル ― 建物を漁り、生きて拠点へ帰れ

ゲーム中は M でミュート切替。操作中のウィンドウだけ音が鳴ります。

操作方法
WASD 移動 / マウス 照準（夜は懐中電灯） / Shift ダッシュ（スタミナ消費）
左クリック 攻撃・使用 / R リロード
1斧 2銃 3ショットガン 4建築・修理 5食料 6救急（ホイールでも切替）
建築中：B 設計図の切替 / 左クリック 設置 / 右クリック 修理
F 調べる・チェスト・作業台 / C クラフト / Q 食事 / H 救急キット
E 長押しで味方を蘇生 / G・中クリック ピン / M ミュート
