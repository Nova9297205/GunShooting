DEAD NIGHTS 2D

2〜3人協力 ポストアポカリプス探索サバイバル ― 建物を漁り、生きて拠点へ帰れ

ゲーム中は M でミュート切替。操作中のウィンドウだけ音が鳴ります。

操作方法
WASD 移動 / マウス 照準（夜は懐中電灯） / Shift ダッシュ（スタミナ消費）
左クリック 攻撃・使用 / R リロード / T 弾種切替（通常弾 ⇄ 徹甲弾・スラッグ）
1斧 2メイン武器 3サブ武器 4回復 5食料（ホイールでも切替）
F ドアの開閉・入れ物の探索・倉庫 / Tab バックパック / C クラフト・武器改造（作業台）
Q 食事 / H 回復 / 物音と懐中電灯の光はゾンビに気づかれる
E 長押しで味方を蘇生 / G・中クリック ピン / M ミュート
