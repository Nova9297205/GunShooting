# DEAD NIGHTS 2D（ゾンビサバイバル＆拠点防衛）

ブラウザで動く 2〜3 人協力（PvE）の見下ろし型ゾンビサバイバルのプロトタイプです。
昼に物資を集めて拠点を強化し、夜を越え、**5 日ごとにやってくる大襲撃（ホード）** を生き延びます。
専用サーバー不要で、PeerJS（WebRTC）によるホスト・ゲスト方式の P2P マルチプレイに対応しています。

- Vite + TypeScript / HTML5 Canvas（外部画像なし。図形・ライティング・パーティクルのみ）
- 見た目は `src/game/Art.ts` の `ArtSet` に集約。スプライト画像版の `ArtSet` を作って差し替えれば画像化できます
- 効果音と BGM は `src/game/Audio.ts` で Web Audio API によりリアルタイム合成（音声ファイルなし）

## セットアップ

```bash
cd zombie
npm install
npm run dev      # http://localhost:5180
npm run build    # 型チェック + 本番ビルド
```

## 操作

| 操作 | キー |
| --- | --- |
| 移動 / ダッシュ | W A S D / Shift |
| 照準（夜は懐中電灯の向き） | マウス |
| 射撃・斧・建築・修理 | 左クリック（長押し可） |
| ツール切替 | 1 拳銃 / 2 斧 / 3 木の壁 / 4 鉄の壁 / 5 ウッドスパイク / 6 修理（B・ホイールでも切替） |
| リロード | R |
| クレートを調べる / アイテム使用 | F（近くに何もなければ救急キットか食料を自動使用） |
| 食事 / 救急キット | Q / H |
| 弾薬クラフト（火薬2 → 弾薬12） | C |
| 蘇生 | ダウンした味方の近くで E を 2.5 秒長押し |
| サウンドのミュート切替 | M |

## ゲームの流れ

- **時間**: 昼 90 秒（06:00〜20:00）＋ 夜 45 秒（20:00〜06:00）で 1 日。画面上部に `Day 1 - 14:30`、次の大襲撃までの日数を表示。
- **昼**: 明るく、ゾンビは遅い。探索・資材集め・建築の時間。
- **夜**: 画面が暗くなり、各プレイヤーの照準方向に懐中電灯の光が伸びる。ゾンビが速くなり、感知範囲も広がる。
- **大襲撃（Day 5, 10, 15… の夜）**: 空と画面端が赤く染まり、ゾンビの大群がプレイヤーめがけて押し寄せる。
  朝 6:00 まで生き延びればクリア（残ったゾンビは朝日で燃え尽きる）。
- **全員がダウン／戦闘不能でゲームオーバー** → 生存日数・撃破数・建築数を表示。

### 資材と物資
| 入手方法 | 得られるもの |
| --- | --- |
| 物資クレート / 収納箱を F で調べる | 弾薬・火薬・食料・救急キット・木材・鉄スクラップ（クレートは時間で再補充、収納箱は毎朝補充） |
| 木を斧で伐採 | 木材（時間で再生） |
| 廃車を斧で解体 | 鉄スクラップ・まれに火薬（時間で再出現） |

木材・鉄スクラップは**チーム共有**、弾薬・火薬・食料・救急キットは**個人の持ち物**です。

### 建築（グリッドに設置）
| 建築物 | コスト | 特徴 |
| --- | --- | --- |
| 木の壁 | 木材 5 | 安い。ゾンビの進路を塞ぐ（耐久 320） |
| 鉄の壁 | 鉄 6 | 高耐久（耐久 950） |
| ウッドスパイク | 木材 4 | 上を通ったゾンビに継続ダメージ＋減速。罠自体も少しずつ壊れる |
| 修理 | 木材 or 鉄 1 / 回 | 壊れかけの壁・罠・セーフハウスの石壁を回復 |

プレイヤーの弾は自分たちの壁・石壁の上を撃ち越せます（木・廃車・廃墟の壁には当たります）。

### ゾンビ
- **ウォーカー**: 標準。**ランナー**: 速いが脆い（主に夜）。**ブルート**: 巨体・高耐久で壁を壊すのが速い（Day 3〜）。
- 徘徊し、プレイヤーを見つける（視線が通る範囲）と追跡。
- **銃声は騒音**: 撃つと周囲のゾンビが音の方へ集まってくる（斧は静か）。
- 追跡中は経路探索（フローフィールド）で回り込み、回り道がなければ進路上の壁を叩き壊して進む。

### サバイバル
- 空腹ゲージは時間で減り、0 になると HP が減り続ける。食料で回復。
- HP 0 でダウン（40 秒のカウントダウン）。味方の E 長押しで HP 50% で復活。時間切れで戦闘不能 → 翌朝キャンプファイアで復帰。

## サウンド

- **BGM**: 昼は穏やかなコード進行、夜は暗いパッドと心音、大襲撃は速いビート。時間帯に合わせて小節の切れ目で切り替わります。
- **効果音**: 銃声・リロード・弾切れ・斧・伐採/解体・建築/修理・壁が叩かれる音/壊れる音・被弾・ゾンビのうめき声/撃破・
  ダウン/蘇生・物資の入手・食事/回復/クラフト・夜の訪れ・大襲撃のサイレン・襲撃クリアのファンファーレ・ゲームオーバー。
- 効果音は**距離で小さくなり、左右に定位**します（画面の外の銃声やうめき声で、敵の方向が分かる）。
- タイトル画面の **BGM / 効果音スライダー**で音量調整（ブラウザに保存）。ゲーム中は **M** でミュート。
- **操作中（フォーカス中）のウィンドウだけ音が鳴ります。** PC 1 台で複数ウィンドウを開いても音が重なりません。
- ブラウザの自動再生制限のため、最初のクリックかキー入力の後から音が鳴ります。

## マルチプレイ（PC 1 台での動作確認）

1. `cd zombie && npm run dev` を実行。
2. ブラウザで **別ウィンドウ** を 2〜3 個開き、横に並べて全部で `http://localhost:5180` を開く
   （タブだと裏のタブが止まるため、ウィンドウを推奨）。
3. 各ウィンドウでプレイヤー名を入力（省略すると P1〜P3。名前はブラウザに保存されます）。
4. ウィンドウ 1 で「部屋を作る（ホスト）」→ ルーム ID を「コピー」。
5. ウィンドウ 2・3 で ID を貼り付けて「部屋に参加（ゲスト）」。`?room=ABC123` を URL に付けても OK。
6. ホストが「ゲーム開始」。操作したいウィンドウをクリックしてから操作する。

シグナリングは PeerJS 公開サーバーを使います。つながらない場合はローカル PeerServer を使えます：

```bash
npx -p peer peerjs --port 9000 --host 127.0.0.1    # 別ターミナルで
cp .env.example .env.local                         # VITE_PEER_HOST / PORT のコメントを外す
npm run dev
```

## ファイル構成

```
src/
  main.ts                 UI制御（タイトル・プレイヤー名・ロビー・リザルト）
  types.ts                型定義（プレイヤー・ゾンビ・弾・オブジェクト・通信パケット）
  game/
    Engine.ts             ホスト権限の計算：昼夜・ホード・ゾンビAI・建築/クラフト・物資・HP/空腹・同期状態
    GameSession.ts        ゲームループ：クライアント側予測・スナップショット補間・オブジェクト差分適用
    Renderer.ts           カメラ・暗闇＆懐中電灯ライティング・建築グリッド・HUD・ミニマップ
    Art.ts                キャラ/オブジェクト/地形のベクター描画（スプライト差し替えポイント）
    Audio.ts              効果音・BGM の合成（音声ファイル差し替えポイント）
    world.ts              タイルワールドとシード付きマップ生成
    physics.ts            移動・壁や建築物との当たり判定
    Effects.ts / Input.ts / constants.ts
  network/
    NetworkManager.ts     PeerJS：ルーム作成・最大2ゲスト・名前・入力/スナップショット中継
```

### 同期のしくみ
- 地形はシードから決定的に生成するため送信不要。木・廃車・クレート・建築物は開始時に一括送信し、以降は**変化分だけ**をスナップショットに載せて送る。
- ホストは 60Hz で計算し、30Hz でスナップショットを配信。ゲストは自機を同じ移動関数で予測し、ホスト確定位置から未処理入力を再適用して補正。
